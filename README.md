# SoftİTO eğitim çalışmaları

Bu depo, [SoftITo eğitim deposundaki](https://github.com/0gsar1m/SoftITo) Python, veri analizi, makine öğrenmesi ve SQL çalışmalarını konu sırasıyla içerir.

## İçerik

- `Python_1`: temel Python ve sınıf alıştırmaları
- `Python_2`: pandas ve istatistik çalışmaları
- `Machine_Learning`: regresyon ve sınıflandırma örnekleri
- `Machine_Learning_2`: ileri makine öğrenmesi örnekleri
- `PostgreSQL` ve `SQLite`: veritabanı dosyaları ve SQL örnekleri

Adında **hoca** veya **hocanın** geçen dosyalar kaynak depodaki biçimiyle korunmuştur. Diğer notebooklara konuya uygun çalışma notları ve değerlendirme hücreleri eklenmiştir. Örnek veri dosyaları, notebookların aynı veri üzerinde çalışabilmesi için korunmuştur.

Notebookları Jupyter veya Google Colab ile açabilirsiniz. Bazı örneklerde yerel veri dosyaları kullanılır; çalıştırmadan önce ilgili dosya yollarını kendi ortamınıza göre kontrol edin. Kullanılan Python paketleri notebookların içindeki import satırlarında görülebilir.
